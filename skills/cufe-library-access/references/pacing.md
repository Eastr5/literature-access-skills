# 取全文的节奏控制：节流参数与停止条件

> ⚠️ 下面的秒数与篇数是**本技能自定的保守值**，用于留出安全余量。
> 出版商与数据库厂商**没有公布**具体阈值，因此这些数字**不得**当作"官方限制"对外引用——
> 它们是"宁可慢"的经验取法。真正有约束力的是各库许可协议里"禁止系统性下载"这一条。

## 一、为什么必须节流（机制，不是礼貌）

订购库的许可协议普遍把"系统性下载"列为违约。触发反爬后，被暂停的是**全校出口 IP 的访问权限**，
不是个人账号——代价是机构级的，恢复要靠图书馆出面申请。
所以节流的目的**不是"尽量友好"，而是避免造成不可逆的机构级损失**。

## 二、两套节奏，不能混用

浏览器路径与 API 路径的风控机制不同，参数不能共用：

| 维度 | API 路径（Crossref / OpenAlex / Unpaywall / 出版商 TDM） | 浏览器路径（订阅全文，走 Chrome） |
|---|---|---|
| 风控依据 | 请求频率、UA | 请求频率 **＋ 行为模式**（导航节奏、标签页数量、鼠标轨迹） |
| 单次间隔 | 2–3 秒 | **20 秒起** |
| 长暂停 | 每 30–50 次，停 60–120 秒 | **每 10 篇，停 3–5 分钟** |
| 并发 | ≤ 2 | **串行、单标签页**，不开多标签并行 |
| 单次会话上限 | 100 篇 | **20 篇**（事先与用户确认） |
| 单日上限 | 无硬上限，但避开高峰时段 | **≤ 100 篇** |

⚠️ `paper-fulltext-harvest` 的默认 `--delay 2.0` 是给 **API 路径**的。
**用它跑浏览器路径太快**，必须显式抬到 `--delay 20`，并配 `--long-pause-every 10 --long-pause-sec 240`。

## 三、按库再分档

中文库的监测比英文出版商更敏感，聚合库的许可条款对导出另有规定：

| 库 | 单篇间隔 | 单次会话上限 | 单日上限 |
|---|---|---|---|
| CNKI / 万方 | ≥ 30 秒 | 10 篇 | 30 篇 |
| Elsevier / Wiley / Emerald / T&F | ≥ 20 秒 | 20 篇 | 100 篇 |
| ProQuest / EBSCO（聚合库） | ≥ 30 秒 | 15 篇 | 50 篇 |
| OA 源（Unpaywall / OpenAlex / PMC / arXiv） | ≥ 2 秒 | 100 篇 | 不限 |

## 四、出现这些信号立即停，不要重试

任一命中即**停止当前平台的取全文操作，冷却 ≥ 30 分钟**，并向用户报告：

- 验证码、滑块（知网、万方、Wiley 的 Cloudflare 挑战页）
- 跳转到登录页，或出现"访问过于频繁"提示页
- HTTP 403 / 429
- 同一地址**连续两次**取回的文件不是 PDF（`%PDF` 文件头校验失败）
- 正文长度骤降（原本有全文的页面只剩摘要）

**升级规则**：同一平台触发两次 → **当日不再对该平台操作**，把待取清单交给用户手动处理。
任务书里凡出现"重试"二字，都要先问一句"这是第几次触发"。

## 五、每次批量前必须做的三件事

1. 与用户确认篇数，并告知本文件里的上限；
2. **先取 1 篇验证链路**，通过再放开；
3. 跑完抽查 5 个随机文件，确认 `%PDF` 文件头与大小（> 50 KB）。

## 六、把它写进循环里（照抄这段）

规则写在文档里容易被忘掉，所以批量脚本一律用下面这个骨架——把间隔和上限变成代码，而不是提醒：

```python
import time

TIERS = {                      # (单篇间隔秒, 单次上限, 长暂停间隔, 长暂停秒)
    "cnki":      (30, 10, 5, 300),
    "aggregator":(30, 15, 8, 300),
    "publisher": (20, 20, 10, 240),
    "oa":        (2, 100, 50, 60),
}

def run_tier(urls, tier):
    gap, cap, every, pause = TIERS[tier]
    if len(urls) > cap:
        raise SystemExit(f"{len(urls)} 篇超过 {tier} 档单次上限 {cap} 篇，先与用户确认并拆批")
    for i, u in enumerate(urls, 1):
        fetch(u)                       # 替换成实际取全文的调用
        if i % every == 0:
            time.sleep(pause)
        else:
            time.sleep(gap)
```

`paper-fulltext-harvest` 已有等价开关，直接用它：
API 路径 `--delay 2`；浏览器路径 `--delay 20 --long-pause-every 10 --long-pause-sec 240`。

## 七、不要做的

- 不做整期、整刊、整个检索式结果集的拉取；
- 不因"第一次全成功"就提高频率——反爬触发常有累积效应，前 10 篇顺不代表第 30 篇安全；
- 不在失败后循环重试同一地址（同一地址最多 2 次）；
- 不绕验证码、不伪造 UA 或指纹来规避检测；被拦就停下报告。
